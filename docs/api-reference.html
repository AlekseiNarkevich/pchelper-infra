PCHelper API (1.0.0)

Download OpenAPI specification:

URL: https://pchelper.by License: Учебный проект, БГУИС

REST API интернет-магазина компьютерных комплектующих PCHelper с конфигуратором сборки ПК и MCP-сервером.

Соглашения

  • Базовый URL версионируется префиксом пути: /api/v1.
  • Все тела запросов и ответов — application/json; charset=utf-8.
  • Даты и время — ISO 8601 в формате UTC: 2026-10-13T09:15:00Z.
  • Денежные величины — целые числа в белорусских рублях (BYN), без копеек.
  • Идентификаторы — целые числа (integer), компоненты каталога имеют собственные пространства идентификаторов, поэтому всегда передаются вместе с типом (componentType + componentId).
  • Пагинация — постраничная: page (с 1) и limit (по умолчанию 20, максимум 100).

Аутентификация

  • POST /auth/login возвращает пару токенов: accessToken (JWT, 30 мин) и refreshToken (opaque, 30 дней).
  • Для всех защищённых конечных точек заголовок Authorization: Bearer <accessToken>.
  • Ошибка 401 означает, что access-токен истёк или неверен — клиент обязан выполнить POST /auth/refresh.

Коды ошибок

Ошибки возвращаются единообразно (RFC 9457, упрощённо):

{ "error": { "code": "VALIDATION_ERROR", "message": "…", "details": [...] } }

Проверка совместимости конфигурации

Прогоняет 8 правил совместимости:

  1. сокет процессора и платы;
  2. тип памяти платы и ОЗУ;
  3. иерархия форм-факторов (Mini-ITX < Micro-ATX < ATX < E-ATX);
  4. длина видеокарты и максимум корпуса;
  5. TDP процессора и охлаждения;
  6. высота кулера / длина радиатора СЖО;
  7. мощность БП ≥ (TDP CPU + TDP GPU) × 1.25;
  8. ровно один SSD и не более одного HDD.
